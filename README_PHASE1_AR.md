# Prompt Image Sorter AI — Phase 1

## ما الذي تم بناؤه في هذه المرحلة

- مشروع Android كامل (Kotlin + Jetpack Compose + Material 3).
- اختيار ملف Prompts عبر Storage Access Framework (بدون صلاحيات Root أو صلاحيات تخزين قديمة).
- اختيار مجلد الصور ومجلد الإخراج، مع حفظ الأذونات (Persistable URI Permissions) — لن يُطلب منك اختيار نفس المجلد كل مرة.
- محرك تحليل ملف الـ Prompts (`PromptParser`) يدعم عدة صيغ ترقيم (`Scene 01 - ...`، `01. ...`، `1 | ...`)، ويرجع تلقائيًا إلى وضع "سطر = مشهد" إذا لم يجد أرقامًا.
- ماسح صور (`ImageScanner`) يقرأ JPG / JPEG / PNG / WEBP فقط، بدون فتح أي صورة كاملة في الذاكرة (بيانات وصفية فقط).
- شاشة رئيسية تعرض عدد الـ Prompts وعدد الصور، وتُظهر التحذيرات (مثل مشهد فارغ).
- **لا يوجد أي AI أو مطابقة وهمية في هذه المرحلة** — زر "بدء المطابقة" موجود في الواجهة لكنه غير مفعّل فعليًا بعد (سيُربط في Phase 3)، تنفيذًا لشرط "عدم بناء Demo وهمي".

## كيف تفتح المشروع

1. افتح Android Studio (يُفضّل أحدث إصدار مستقر، مثل Ladybug أو أحدث).
2. من الشاشة الرئيسية اختر **Open**.
3. اذهب إلى المجلد الذي فككت فيه هذا الملف، واختر مجلد `PromptImageSorterAI` بالكامل (وليس مجلدًا فرعيًا).
4. اضغط **Trust Project** إذا ظهرت رسالة ثقة.
5. انتظر حتى ينتهي **Gradle Sync** (يظهر شريط تقدم أسفل النافذة).

> ملاحظة مهمة: هذا المشروع **لا يحتوي على Gradle Wrapper** (ملفات `gradlew` الثنائية) لأنني لا أستطيع توليد ملفات ثنائية هنا. إذا طلب منك Android Studio "Gradle wrapper is missing"، اختر الخيار الذي يقول **"Use Gradle from: Specified location"** في `File > Settings > Build Tools > Gradle` وحدد التثبيت المرفق مع Android Studio نفسه، أو اضغط على الاقتراح التلقائي لإنشاء الـ Wrapper إن ظهر. هذه خطوة تحدث مرة واحدة فقط.

## كيف تبني وتشغّل

1. بعد نجاح Gradle Sync، تأكد من ظهور جهاز Samsung Galaxy S25 Ultra (أو أي جهاز/محاكي Android 13+ فأعلى) في القائمة أعلى النافذة.
2. اضغط زر **Run ▶** الأخضر.
3. أول مرة فقط، قد يطلب منك تفعيل "تثبيت من مصادر غير معروفة" على الجهاز — وافق.

## ماذا تتوقع أن يظهر

- شاشة بعنوان "Prompt Image Sorter AI" فيها 4 أزرار: اختيار ملف Prompts، اختيار مجلد الصور، اختيار مجلد الإخراج، بدء المطابقة (غير مفعّل).
- بطاقة "ملخص المشروع" تعرض "عدد الـ Prompts: 0" و"عدد الصور: 0" في البداية.

## كيفية اختبار هذه المرحلة

1. أنشئ ملف نصي بسيط باسم `prompts.txt` يحتوي مثلاً:
   ```
   Scene 01 - رجل بدائي يقف أمام كهف
   Scene 02 - الرجل نفسه يجمع الحطب
   ```
2. اضغط **اختيار ملف الـ Prompts** واختره — يجب أن يتحول الرقم في "عدد الـ Prompts" إلى 2.
3. اضغط **اختيار مجلد الصور** واختر أي مجلد فيه بضع صور JPG/PNG — يجب أن يتحول "عدد الصور" لعدد الصور الموجودة (الصور غير المدعومة يتم تجاهلها بصمت).
4. اضغط **اختيار مجلد الإخراج** واختر أي مجلد (حتى لو فارغ).
5. زر "بدء المطابقة" يجب أن يصبح قابلًا للضغط (enabled) الآن — لكنه لا يفعل شيئًا بعد، وهذا متوقع في Phase 1.
6. أغلق التطبيق وأعد فتحه — لاحظ أنه لن يطلب منك الأذونات من جديد لنفس الروابط إذا استخدمتها ضمن نفس الجلسة (الحفظ الكامل عبر إعادة تشغيل الجهاز يُستكمل في Phase 5 مع Project History).

## مشاكل محتملة

- **"Gradle wrapper is missing"**: راجع الملاحظة أعلاه.
- **فشل التزامن بسبب إصدار JDK**: تأكد أن Android Studio يستخدم JDK 17 (Settings > Build Tools > Gradle > Gradle JDK).
- **الصور لا تظهر رغم وجودها**: تأكد أن امتداد الملفات هو فعليًا jpg/jpeg/png/webp (وليس مثلاً heic غير مدعوم حاليًا).
